## 📖 Overview

**Beyond the Surface** is an immersive, scroll-driven web experience that takes users on a cinematic journey through Earth's ocean layers. As visitors scroll deeper, they discover different marine ecosystems enhanced with smooth parallax animations, atmospheric visuals, and ambient sound.

The project combines storytelling, interactive design, and modern front-end development to create an engaging educational experience.

---

## ✨ Features

- 🌊 Smooth parallax scrolling
- 🐋 Multi-layer ocean depth exploration
- 🐠 Dynamic marine life animations
- 💡 Atmospheric lighting effects
- 🎵 Ambient ocean soundscape
- 📱 Fully responsive design
- ⚡ Smooth CSS animations
- 🎨 Modern immersive UI/UX
- 🚀 Optimized performance

---

## 🌍 Ocean Journey

The experience guides users through multiple ocean depth zones:

- ☀️ Surface Zone
- 🌊 Sunlight Zone
- 🌌 Twilight Zone
- 🌑 Midnight Zone
- 🕳️ Hadal Trench

Each section introduces unique visuals, animations, and environmental effects.

